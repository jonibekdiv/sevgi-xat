# Sevgi xat 💌

Zarrachalardan yasalgan animatsion "xat" sayti: konvert → aylanma galaktika → ism → atirgul.

Ism: **Charos**.

## Tugmalar
- **QR** — saytning QR kodi
- Sichqonchani (telefonda barmoqni) yurgizsangiz atirgul aylanadi
- **ASCII** — zarrachalarni belgilar ko'rinishiga o'tkazadi
- **♥ Ovoz** — fon musiqasi (WebAudio, tashqi fayl yo'q)
